## البيئة والأوامر
- PostgreSQL 16.2 (pgserver، مقبس `/tmp/erppg`)، عامل uvicorn **واحد**، 2 vCPU / 3GB — عتاد أضعف من أي staging حقيقي.
```bash
cd backend && .venv/bin/python scripts/load/pg_start.py /tmp/erppg
export DATABASE_URL="postgresql+asyncpg://postgres@/brokerhub_load?host=/tmp/erppg" INTEGRATIONS_DRIVER=sim ENV=dev
.venv/bin/python -m alembic -c alembic.ini upgrade head && .venv/bin/python -m app.seed
PYTHONPATH=. .venv/bin/python scripts/load/erp_volume.py --rows 50000 --clients 200   # → clients total=200 · ledger_after=50004
DATABASE_URL=... .venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8021
.venv/bin/locust -f scripts/load/erp_locustfile.py --headless -u 20 -r 5 -t 3m30s \
  --host http://127.0.0.1:8021 --csv docs/qa/load/raw/erp-r11 --only-summary
```
البيانات: 200 عميل، **50,004 قيد ledger posted** موزعة على 12 شهرًا والأنواع الستة (type×direction)،
20 مستخدمًا متزامنًا (manager) لمدة 3m30s، منها شريحة كتابة post+void على قاعدة الحمل فقط.
