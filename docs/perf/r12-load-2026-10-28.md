# Load test — R12 Channels (2026-10-28)

كل رقم أدناه من تشغيل فعلي في هذه الجلسة؛ الخام في `docs/qa/load/raw/r12-*.csv`. البوابات لم تُخفَّض.

## البيئة والأوامر
- 2 vCPU / 4GB RAM، PostgreSQL 16.2 (pgserver، مقبس `/tmp/r12pg`)، **uvicorn عاملان** (`--workers 2`) على `:8022`، `ENV=dev INTEGRATIONS_DRIVER=sim` (ويبهوكات المحاكاة dev فقط — ADR-029؛ بوابات التوقيع الحقيقية مُثبتة في pytest للسائق الحيّ).
- الحجم: `r12_volume.py --requests 20000` → **20,100 طلب** (whatsapp 4.4k/call 2k/email 2k/manual 2k + بذرة) و5,951 مرفقًا بملفات حقيقية في التخزين؛ و`erp_volume.py --rows 100000` → **100,004 قيد ledger**.

```bash
cd backend && .venv/bin/python scripts/load/pg_start.py /tmp/r12pg   # + CREATE DATABASE brokerhub_load
export DATABASE_URL="postgresql+asyncpg://postgres@/brokerhub_load?host=/tmp/r12pg" INTEGRATIONS_DRIVER=sim ENV=dev STORAGE_DIR=/tmp/r12-objects
.venv/bin/python -m alembic -c alembic.ini upgrade head && .venv/bin/python -m app.seed
PYTHONPATH=. .venv/bin/python scripts/load/seed_volume.py --reps 10
PYTHONPATH=. .venv/bin/python scripts/load/r12_volume.py --requests 20000     # requests_total=20100 attachments_total=5951
PYTHONPATH=. .venv/bin/python scripts/load/erp_volume.py --rows 100000 --clients 200  # ledger_after=100004
.venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8022 --workers 2
LOAD_MODE=intake    .venv/bin/locust -f scripts/load/r12_locustfile.py --headless -u 10 -r 5  -t 45s --host http://127.0.0.1:8022 --csv docs/qa/load/raw/r12-smoke  --only-summary
LOAD_MODE=inbox     .venv/bin/locust -f scripts/load/r12_locustfile.py --headless -u 50 -r 10 -t 3m  --host http://127.0.0.1:8022 --csv docs/qa/load/raw/r12-inbox  --only-summary
LOAD_MODE=media     .venv/bin/locust -f scripts/load/r12_locustfile.py --headless -u 20 -r 5  -t 2m  --host http://127.0.0.1:8022 --csv docs/qa/load/raw/r12-media  --only-summary
LOAD_MODE=mixed     .venv/bin/locust -f scripts/load/r12_locustfile.py --headless -u 50 -r 10 -t 12m --host http://127.0.0.1:8022 --csv docs/qa/load/raw/r12-mixed  --only-summary
.venv/bin/locust -f scripts/load/erp_locustfile.py --headless -u 20 -r 5 -t 3m --host http://127.0.0.1:8022 --csv docs/qa/load/raw/r12-erp --only-summary
BASE=http://127.0.0.1:8022 PYTHONPATH=. .venv/bin/python scripts/load/r12_verify.py
```

## القرار
**FAIL on this hardware** لبوابات زمن القائمة/الويبهوك تحت المزيج وبوابة ERP عند 100k — بالأرقام أعلاه، بلا تخفيف.
السبب المقاس: عاملان على 2 vCPU يتقاسمهما ‏`/requests` list (payload ‏16KB/صفحة) ومسارات المال الثقيلة؛ كل مسار منفردًا يجتاز بوابته أو يقترب. على staging بعدّة عمّال/أنوية يُعاد القياس بنفس الملفات والأوامر حرفيًا قبل أي ادّعاء نجاح.
ما **نجح** وظيفيًا تحت الحمل: صفر 5xx، صفر مضاعفات، عزل 403/403، توقيعات الويبهوك، وتنزيلات موقّعة بترويسة cache-control (يفشل الاختبار صراحة عند غيابها).
