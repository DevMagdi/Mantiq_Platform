# لقطات المراجعة (design review captures)

تُولَّد آليًا من `frontend/e2e/screenshots.spec.ts` — من مجلد `frontend`:

```bash
E2E_SKIP_WEBSERVER=1 npm run e2e -- screenshots   # عند تشغيل الخدمتين يدويًا
npm run e2e                                       # أو ليقلّع Playwright الخدمتين بنفسه
```

الملفات الناتجة:

| الملف | المحتوى |
| --- | --- |
| `01-dashboard.png` … `16-login.png` | الشاشة رقم N من §9 بالاسم الثابت الذي تطلبه المواصفة (1440×900، و`04-mobile-leads.png` وحدها 390×844) |
| `NN-<screen>@390x844.png` | لقطات إضافية لنفس الشاشة على المقاس Mobile (صندوق الطلبات والبوابة) |
| `contact-sheet.png` | الشاشات الست عشرة في صورة واحدة للمراجعة السريعة |

CI يرفع المجلد كـ artifact باسم `screenshots` (وظيفة `e2e`)، ولا يلتزم برفع الصور إلى المستودع
تلقائيًا — قرار الإبقاء/الحذف بعد المراجعة البصرية لصاحب المشروع.

لا تُحرَّر الصور يدويًا: أي تغيير فيها يعني تغيير الواجهة، واللقطة يجب أن تُعاد من الاختبار.
